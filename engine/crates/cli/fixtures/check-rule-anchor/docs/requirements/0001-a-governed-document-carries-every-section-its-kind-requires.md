# A governed document carries every section its kind requires

## Context

This document is a fixture. It exists so that one run of the binary reports both arms of one question: a check rule this engine ships, and a string that looks like one and is not.

## Requirement

A document of a kind that declares required sections carries a heading for every one of them.

## Verification

`section.required.missing` is the rule, and the entry above points at it. `no.such.rule` is the second entry, and this engine ships no rule of that name.
