# The second live document

## Context

A step that named one document would pass a test that a step naming the wrong document also passes. Two subjects tell the two apart.

## Decision

The status of this document is `current`, and that is the whole of what the migration payload beside it is about.

## Consequences

A candidate taxonomy that moves `current` stops this document validating, and the payload states which step covers it.
