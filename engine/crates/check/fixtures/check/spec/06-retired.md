# Retired

The failing fixture for the enum rule. `status` admits `draft`, `current` and
`superseded`, and this document declares `retired`. The finding anchors at the
value, because that is the text to change, and the remediation names the whole
admitted set: which one is correct is a statement only this document's author
can make.
