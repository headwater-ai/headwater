# An identifier that is not a word

An identifier is a word. A sequence of two is a document that has not decided which one it is, and the identifier index carries neither of them.

This document declares no relation, so it separates the defect in its identity from the cost that `16-no-identifier.md` shows. The pattern rule reads nothing here either, and it skips with the key it looked under in the reason.
