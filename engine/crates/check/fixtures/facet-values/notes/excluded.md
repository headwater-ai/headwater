# The note at a basis its own kind excludes

`measured` is a value of `evidence_basis` and `record` above this kind admits
it. `note` narrows to `cited` alone, so the narrowing that excludes this
document is the one on its own kind, and `rulings/admitted.md` carries the same
value and is silent.
