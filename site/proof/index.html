03

What works, and what is unproven

Working. The engine runs. This repository types its own documentation, checks it on every commit, and scaffolds, explains, routes, generates and exports it. It consumes its own taxonomy as a pinned published package, not as a local file.

Measured. Two experiments asked whether Headwater helps an AI agent. The counterfactual campaign of 2026-09-30 measured it by component, with parts removed. The documents under docs/ have a large measured effect on whether an agent gives a sufficient answer, and the campaign found no detectable gain from the hooks and skills. The evaluation states each figure, with its interval and its cost. The tuning round of 2026-10-20 to 2026-10-25 then rewrote the skills in two kept rounds and measured them on five harder probes. The pass rate rose by a large margin over the documents and the engine alone, and the confirmation states the figure. That result is tuned: the rewrites were chosen on those probes, and the round that tests them on probes no rewrite saw has not run.

Unproven. The hook is in tuning and has shown no gain yet. No experiment measured the MCP server or the quality of governance itself, and those efficacy claims stay open until one does. The work still open is on the milestones page.

Installing. v0.6.1 carries a static Linux x86_64 archive and a macOS arm64 archive, each with a checksum. The release workflow runs both on a host with no Rust toolchain before it creates the release, so the download needs no toolchain. cargo install headwater-cli --locked is the alternative, and crates.io serves v0.6.1. The install page has each route.

04

How to check this page yourself

This page is a self-assessment: the project measured itself, and that is the weakest form of evidence.

You can repeat it. The repository is public, and sh tools/site/refresh-figures.sh --print runs the engine over it and prints each figure on this page. The script reads headwater check --json, the obligation register, the generated command index and the list of export formats in the engine source.

The missing part is one we cannot supply alone. Nobody has yet measured this engine on documentation that is not ours.

The source of this project is github.com/headwater-ai/headwater, under Apache-2.0. The engine, the taxonomy library and the corpus these pages describe are all in it.
