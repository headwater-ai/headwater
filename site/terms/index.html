Terms

Status: the engine runs, and nothing is released. The owner ratified every term below, and they hold whether or not a release exists.

The code

The engine, the library, the base package and the bundles are under Apache-2.0.

The choice of Apache-2.0 over MIT rests on two clauses. Apache-2.0 grants a patent license that MIT does not grant, and this tool emits artifacts into other people's compliance pipelines. Apache-2.0 also reserves the trademark.

The prose

The prose under docs/ is under Creative Commons Attribution 4.0. The code samples embedded in that prose stay under Apache-2.0, so that a reader who copies an example carries no attribution obligation.

Contributions

Contributions arrive under the Developer Certificate of Origin, and a contribution carries a Signed-off-by line. There is no contributor license agreement.

The reason is stated positively rather than as a preference. The one power a contributor agreement adds is the power to change the terms later without asking, and this project does not want it.

Why not copyleft

Copyleft was refused for a stated reason rather than by taste. The library has to embed in another process, and an obligation that reaches a linked work reaches software the adopter owns.

The base package and the bundles impose nothing on a taxonomy derived from them. An adopter's overlay resolves against the base, so the resolved lock contains base content. A share-alike term on the base would therefore reach an artifact that belongs to the adopter. Customizing the taxonomy never means forking the tooling, and this paragraph is that sentence in its legal form.

Trademark

The project claims no registered mark, and a TRADEMARKS.md in the repository states that position. Apache-2.0 section 6 grants no trademark rights, and that reservation was one of the two reasons to prefer these terms to MIT.

Notices in the source

A source file carries SPDX-License-Identifier: Apache-2.0 on the first line that admits a comment, and it carries no per-file copyright line. The identifier is the whole header, because a copyright line goes stale and the commit history does not.

Security reports

A coordinated-disclosure process exists, and a SECURITY.md in the repository carries it. It reports that no engine has shipped, so no released artifact can carry a defect yet. It also states what is out of scope by design, which is a reader who can clone a repository and then reads it.

The date

These terms carry a date, and the date is 2026-08-11. A term with no date cannot later be shown to have changed, and a visible change is the whole value of the commitment.

There is no link to the source or to the specification here, because the repository is not public. The project has decided that this repository becomes public, and the date belongs to the owner.
