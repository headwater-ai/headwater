The Headwater namespace

https://w3id.org/headwater/

Status: specification, pre-implementation. No engine has shipped, so no artifact carries these identifiers yet. This page reserves and documents them.

Every artifact Headwater emits carries identifiers under this namespace. It is a permanent identifier served by w3id.org, which the W3C Permanent Identifier Community Group operates, and it redirects here.

What resolves under it

PrefixWhat it identifies
taxonomy/Taxonomy schemas — shelves, document kinds, facets, relations. The LinkML form declares this as its default prefix.
shapes/SHACL node shapes and constraints generated from a taxonomy.

Both appear in the worked examples: the LinkML schema and the SHACL shapes.

Why not this domain

A namespace URI inside an emitted artifact is a promise about a name that outlives every release. A domain rented by the year is a weak vehicle for a promise of that length, and an adopter who holds a generated artifact should never depend on who renews what.

So the identifier and the web address are separate assets. w3id.org holds the identifier, and it redirects to whatever location this project hosts. A later change of domain reaches no artifact anyone already holds. LinkML publishes its own metamodel at https://w3id.org/linkml/ for the same reason.
