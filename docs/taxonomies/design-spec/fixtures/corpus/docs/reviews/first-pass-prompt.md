# First pass over the core model

## What the reviewer reads

[1 — The core model](../spec/01-model.md), at the revision current on the date of the run.

## What the reviewer is asked

1. Which term in the model would a new operator define wrongly?
2. Which claim in the model has no evidence behind it?
3. Which part of the model would change if a second destination type arrived?

## What counts as a finding

A finding names a sentence and states what a reader would get wrong. A preference about wording is not a finding.

## Out of scope

Transport, retry, and anything about cost.
