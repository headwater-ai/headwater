# 13 — Open obligations

## Unmeasured claims

- **The retry ladder reaches a delivery rate above 99 percent within four attempts.** The instrument is a replay of one month of production traffic against the ladder, and nobody has run it.

## What waits on a first adopter

- **A second destination type.** The model claims that a destination is a parameter rather than a branch, and only one destination type exists.

## Design work that nothing blocks

- **The retention window.** Q1 left it open, and the cost model needs one number that nobody has priced.
