# Publish a release

## Scope

An operator who publishes a Beacon release. The document is a how-to guide and its `reader_mode` says `cookbook`, which is a word the tradition does not use.

## Behavior

1. Tag the commit.
2. Build the artifact and read its digest back.
3. Publish the artifact under the tag, and record the digest beside it.

`cookbook` is the planted defect of this corpus. It is a name for the same idea that `how-to` names, and it is the failure a closed value set exists to catch: two words for one mode, and a reader who filters on one of them sees half the pages.
