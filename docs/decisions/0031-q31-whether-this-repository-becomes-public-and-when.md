# Q31 — Whether this repository becomes public, and when

## Context

The repository is private. Two records already settle the posture around it and neither settles this. [HW-DR-0011](0011-license-and-distribution-posture.md) ratified Apache-2.0 on 2026-08-11 for the engine, the library, the base package and the bundles. [HW-DR-0016](0016-public-presence.md) settled what a public presence is, and it holds that the site is a projection of this corpus. Neither one says whether anybody outside this repository may read the repository.

**The absence costs a run every time it meets one.** The build order carries a list of standing escalations, and this question sits on it as undecided. An undecided question invites a run to reopen the argument, so each run pays the same cost and leaves the answer where it was.

**A large part of the obligations shelf waits on the answer.** A record that waits for an adopter waits for a corpus that another organization keeps. No work of this repository discharges one, and nobody outside can bring one while the repository is unreadable.

## Decision

**This repository becomes public on 2026-09-08.**

**The owner set the date.** The schedule is not an open question, and this record stops each run from raising it as one.

**The posture is what the other records needed and did not have.** Apache-2.0 already permits redistribution, and the site is already a projection of this corpus. Both stand on a repository that a reader can reach. This record supplies that premise and asks the two earlier records for nothing.

**The date belonged to the owner alone.** No measurement, build or adopter produced it. The owner set 2026-09-08 under the `ruling` shape [HW-DR-0030](0030-q30-whether-what-an-obligation-waits-on-is-a-state-or-a-property-and-how-many-values-it-takes.md) names.

## Consequences

**The posture and date leave the escalation list.** A run that meets this question reads this record and cites it. The date is no longer a ruling that the corpus owes.

**Work that waits on an outside adopter still waits.** A readable repository is a precondition of an adopter and not an adopter. The records on the obligations shelf that wait for a corpus somebody else keeps are unmoved by this record.

**Nothing here changes the license, the trademark posture or the commercial tier.** [HW-OBL-0094](../obligations/0094-where-a-commercial-tier-could-sit-and-how-thin-the-trademark.md) records that the trademark and commercial tier posture rests on one line of a README, and it stands where it stood.

**The date was the one thing this record did not carry.** [HW-OBL-0130](../obligations/0130-the-publication-date-of-this-repository-is-unset-and-the-owner-alone-sets-it.md) held that debt until the owner set the date.
