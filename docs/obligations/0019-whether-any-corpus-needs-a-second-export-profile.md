# Whether any corpus needs a second export profile

## Context

[Q17](../spec/09-decisions.md#q17--governed-access-and-the-solution-layer) rules how governed access works and admits an export profile per audience. Whether any corpus ever needs a second one is open.

## Obligation

The corpus owes a second profile, or a statement that one audience is enough.

## Discharge

The first release ships one profile, unfiltered, and a real adopter with a real second audience is what builds the rest.

This item is data or a deferred component, so the first real adopter is the evidence rather than a further argument.
