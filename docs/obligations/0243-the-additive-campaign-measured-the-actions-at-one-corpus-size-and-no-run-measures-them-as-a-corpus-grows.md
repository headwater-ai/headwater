# The additive campaign measured the actions at one corpus size and no run measures them as a corpus grows

## Context

[HW-DR-0112](../decisions/0112-the-additive-campaign-measures-eleven-actions-by-five-layers-in-seven-scenarios.md#the-circumstance-axes) names three circumstance axes that the additive campaign defers and records as debt. Corpus size is the first. The campaign said to record them after its last paid session, and phase B on #1881 was that session. [the evaluation of phase B](../evaluations/what-the-additive-campaign-measured-for-the-eleven-actions-headwater-supports.md) states each row on this repository alone, at the size it had at the pin of phase B.

## Obligation

The corpus owes a measurement of how the pass rate of an action changes with the size of the corpus. A larger corpus gives more candidates for each question, and a smaller one gives fewer documents to cite. Either one can move a row. Nothing in the campaign varied the size, so no row of the evaluation says that its rate holds at another size.

## Discharge

This record discharges when a run measures at least one row of the evaluation on two corpora of different size. The probes and the layers must be the same. The run must state each size and the difference between the rates, with its interval.
