# One of the four warrant values has no instance in this corpus

## Context

Every authored document here is `accepted`, because a human merged each one. `regenerated` has an instance now. [`docs/spec/README.md`](../spec/README.md) is the generated index of the specification shelf. The census reads that warrant off the marker rather than out of a declaration, and that file carries the marker on its first line.

## Obligation

Nothing is `transcribed`, because no external system of record feeds this repository. `asserted` no longer stands beside it. `headwater taxonomy audit` reports nine documents under that warrant on 2026-08-15: three probes, four obligation records, [15 — The recorder contract](../spec/15-the-recorder-contract.md) and [DR-repo-0024](../decisions/0024-q24-readability-and-what-a-sweep-can-be-asked-about.md). A figure here is a figure that only a person re-derives, and the verb that produces it is named for that reason. Four engine rules turn on the value, and this corpus exercises three of them.

## Discharge

The `transcribed` branch runs over corpus content, and not over the census fixture tree alone. It waits on an importer, which does not feed this repository. What the `asserted` instances found is a second question, and [OBL-repo-0126](0126-every-asserted-document-carries-the-freshness-date-that-spec-3-says-it-cannot.md) holds it rather than this record.
