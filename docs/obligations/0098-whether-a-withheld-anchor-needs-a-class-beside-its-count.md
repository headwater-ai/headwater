# Whether a withheld anchor needs a class beside its count

## Context

[Q17](../spec/09-decisions.md#q17--governed-access-and-the-solution-layer) rules that a withheld anchor is counted rather than hidden.

## Obligation

The corpus owes a ruling on whether a withheld anchor needs a class beside its count.

## Discharge

This corpus withholds nothing, so no run has ever printed such a count and no reader has ever asked what it meant.
