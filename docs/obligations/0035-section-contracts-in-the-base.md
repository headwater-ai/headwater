# Section contracts in the base

## Context

The base `specification` kind requires the sections `Scope` and `Behavior`. That is a lexical commitment inside a package whose [core](../spec/07-distribution-and-federation.md#the-invariant-core) is semantic and never lexical.

## Obligation

A tradition with other headings cannot reuse the kind add-only, so it adds a parallel behavior kind. The base kind and its shelf then hold nothing.

## Discharge

The [first-run walkthrough](../evaluations/default-taxonomy-first-run.md#the-starter-kit-is-a-selection-not-a-third-option) reached the same finding about the controlled-language profile. The remedy is the same one: an opinionated default belongs to the starter kit.
