# Whether the read set of a real corpus is small enough that publishing it is free

## Context

[Q21](../spec/09-decisions.md#q21--terminological-succession-and-validity-under-merge) asks a run to publish the union of its in-scope inputs. Whether the read set of a real corpus is small enough that publishing it is free is open.

## Obligation

The corpus owes a reading of that cost at a corpus other than this one.

## Discharge

It is free on this one. The artifact holds one line per document. Over this repository it is 4,708 bytes against the 1,272,450 bytes of the 36 documents that it describes. That is 0.37 per cent.

The per-document cost is about 106 bytes, so the fraction is a ratio against the size of an average document rather than a constant. This corpus writes long documents, and a corpus of 2,000-byte documents pays about 5 per cent.
