# Whether a solution corpus vendors each source export or references it

## Context

[Q9](../spec/09-decisions.md#q9--multi-repository-corpora) rules that the tier above harvests pinned exports. Whether a solution corpus vendors each source export or references it is open.

## Obligation

The corpus owes a ruling on the arrangement. A vendored copy keeps checks offline and grows the repository, and a reference does the reverse.

## Discharge

The size of one real harvest is the evidence that closes it, and no such tier exists yet.

This item is data or a deferred component, so the first real adopter is the evidence rather than a further argument.
