# The friction signal that Q4 narrowed is still unread

## Context

[Q4](../spec/09-decisions.md#q4--relation-storage) refused the annotated prose link and made the friction a check instead. The friction signal survives in a narrower form.

## Obligation

The corpus owes a reading of that signal: the rate at which authors declare the same link twice.

## Discharge

If authors still declare the same link twice at a rate the fix does not absorb, this ruling is wrong and the annotation question returns. Nothing reads that rate today.
